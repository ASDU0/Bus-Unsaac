# Carpeta de Imágenes - Día 4

Esta carpeta está destinada para almacenar las imágenes de la aplicación de navegación.

## Uso
- Coloca aquí las imágenes que quieras usar en la aplicación
- Asegúrate de referenciarlas correctamente en el archivo `pubspec.yaml`
- Formatos soportados: PNG, JPG, GIF, SVG

## Posibles mejoras
- Logo de la aplicación
- Iconos personalizados para cada pantalla
- Imágenes de fondo
- Avatars de usuario personalizados

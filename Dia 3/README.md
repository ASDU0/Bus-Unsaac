# 📱 Día 3 - UI de Perfil con Widgets Básicos

## 📋 Descripción
Aplicación móvil Flutter que implementa una interfaz de usuario de perfil completa utilizando widgets básicos. Esta aplicación demuestra el uso de varios componentes fundamentales de Flutter para crear una UI atractiva y funcional.

## 🎯 Objetivos del Proyecto
- Implementar widgets básicos de Flutter
- Crear una UI de perfil atractiva y profesional
- Usar widgets de layout como Column, Row, Container
- Implementar interactividad básica con botones
- Aplicar estilos y temas

## 🚀 Características Implementadas

### Widgets Básicos Utilizados:
- **Scaffold**: Estructura básica de la pantalla
- **AppBar**: Barra superior con título y acciones
- **Container**: Contenedores con decoración y styling
- **Column & Row**: Layouts verticales y horizontales
- **Text**: Textos con diferentes estilos
- **ElevatedButton**: Botones elevados con interactividad
- **Icon**: Iconos de Material Design
- **CircleAvatar**: Avatar circular para foto de perfil
- **Card**: Tarjetas con sombras
- **Padding**: Espaciado interno
- **SizedBox**: Espaciado fijo
- **SingleChildScrollView**: Scroll vertical
- **Stack**: Superposición de widgets
- **Positioned**: Posicionamiento absoluto
- **Wrap**: Layout flexible para chips

### Funcionalidades:
1. **Header con Gradiente**: Fondo degradado atractivo
2. **Foto de Perfil**: Avatar con borde y sombra
3. **Estadísticas**: Publicaciones, seguidores y siguiendo
4. **Botones Interactivos**: 
   - Botón seguir/siguiendo con estado
   - Botón de mensaje
5. **Información Personal**: Lista con iconos y datos
6. **Chips de Intereses**: Tags de tecnologías e intereses
7. **Navegación**: AppBar con botón de configuración

## 🎨 Diseño
- **Colores**: Paleta azul profesional
- **Tipografía**: Roboto (fuente por defecto de Material Design)
- **Espaciado**: Consistente y bien distribuido
- **Sombras**: Para dar profundidad a los elementos
- **Bordes Redondeados**: Para un look moderno

## 📱 Cómo Ejecutar
1. Asegúrate de tener Flutter instalado
2. Navega a la carpeta del proyecto:
   ```bash
   cd "Dia 3"
   ```
3. Obtén las dependencias:
   ```bash
   flutter pub get
   ```
4. Ejecuta la aplicación:
   ```bash
   flutter run
   ```

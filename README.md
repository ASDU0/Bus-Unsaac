# 📱 Dart & Flutter Learning
Esta rama está dedicada al aprendizaje y desarrollo de aplicaciones móviles en 2 semanas con un reto cada día.

## 🎯 Objetivo
Este proyecto tiene como finalidad aprender y practicar el desarrollo de aplicaciones móviles utilizando:

- **🎯 Dart**: Lenguaje de programación moderno y eficiente
- **📱 Flutter**: Framework para desarrollo multiplataforma

## 📝 Descripción
Proyecto de práctica y experimentación con Dart y Flutter, enfocado en el aprendizaje de conceptos fundamentales y mejores prácticas del desarrollo móvil.

## 📋 Prerrequisitos
- Flutter SDK instalado
- Editor de código (VS Code recomendado)
- Conocimientos básicos de programación
